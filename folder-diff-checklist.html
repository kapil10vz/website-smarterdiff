Folder Diff Checklist

Use folder comparison when validating release outputs, backup integrity, or migration copies.

Review order

  1. Check files only-in-A and only-in-B.
  2. Review modified files in sensitive paths first.
  3. Confirm expected generated files are present.
  4. Document exceptions before sign-off.
