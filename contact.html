Common questions

Is SmarterDiff really free? Yes. We're funded by ads. No premium tier, no paywall, no hidden costs. Compare as many files as you want.

Does it work on my phone? Yes, it's responsive. All the same features work on mobile — but we recommend a larger screen for the split-pane diffs.

Can I use it offline? After the first load (when libraries are cached), yes — close your WiFi and compare files. Everything runs in your browser's memory.

Is it open-source? The libraries we use are open-source (jsdiff, mammoth.js, SheetJS, pdf.js). We're committed to transparency about how the tool works.

Report a bug

Found something broken? Let us know. Include the file format you were comparing, your browser (Chrome, Firefox, Safari, Edge), and what you expected vs. what happened. Screenshots or sample files are super helpful.

Feature requests

Want to compare JSON files? LaTeX documents? MP3 metadata? Tell us what format you need. We prioritize requests from users in professional workflows — lawyers, developers, journalists, analysts.
